# Cổng Thông Tin Lâm Nghiệp & Địa Không Gian Số

Ứng dụng web giới thiệu, tra cứu thông tin chuyên ngành Lâm nghiệp, Văn bản pháp luật hợp nhất (VBPL), Cơ sở dữ liệu Động - Thực vật rừng, Khóa học E-Learning và Hệ sinh thái ứng dụng GIS.VN / Bảo Vệ Rừng.

## Công nghệ sử dụng
- React 19 + TypeScript
- Vite 7
- Tailwind CSS v4
- Lucide React Icons

## Cài đặt & Chạy local
```bash
npm install
npm run dev
```

## Build bản production (1 file HTML độc lập)
```bash
npm run build
```
